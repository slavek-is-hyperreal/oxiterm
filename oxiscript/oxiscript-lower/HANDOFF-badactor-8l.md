# BAD ACTOR 8.L handoff (update after each finding)
Harness: tests/bad_actor_8l.rs (probe sweep + failing finding tests), tests/bad_actor_8l_fuzz.rs (generator, long loop #[ignore]).
Run: CARGO_BUILD_JOBS=2 cargo test --release -p oxiscript-lower --test bad_actor_8l -- --nocapture
## Findings
L01 medium LEAK: template literal accumulator not held across a later `?` (expr.rs `template`, comment says it keeps acc alive but does nothing). Repro: `Ok(`${pre}-${bad()?}`)` leaks 1 object. Tests try_tpl_a/b/c, try_template_second_fails, order_try_in_nested_positions.
L02 medium SEMANTICS: `for (let i...) { fs.push(() => i) }` shares ONE cell across iterations (prints 333, TS/JS 012). grammar.md only promises fresh binding for for-of. Test cl_loop_var_capture.
L03 medium GAP (broader than ??): any use of a nullable local whose narrowed type is exactly `null` (`const s: string | null = null;` then `s === null`, pass to nullable param, return, store in field, array literal, `??`) -> OXS-E0700. `let best: T|null = null` assigned in a loop works. Tests l03_*. Original: `s ?? x` -> OXS-E0700 "bare null value without a nullable context" (checker narrows s to null). Test try2_nullcoalesce_rhs.
L04 info: closure cycles (self-referencing closure var `fib`, class field closure capturing its instance) leak under Stub runtime (no cycle collector, expected; 8.M). Tests cl_recursion_via_closure_var, cl_class_field_closure_capturing_self.
