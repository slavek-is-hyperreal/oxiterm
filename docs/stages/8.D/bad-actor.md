## Tested (numbers)
- Fuzz: 5,150 mutated/random programs (templates + all 127 repo `.oxs` as seeds; token insertion, deletion, line dup, CRLF/BOM/NUL/astral/U+2028/control chars, 10% random bytes), each through `check --stdin --json`, `fmt --stdin`, `fmt` of fmt output, `check` of fmt output, and `check --fix` on a file with re-run: 0 panics/signals/timeouts, exit codes always 0/1, JSON always valid, all ranges within the file, utf16 column exact in every case, fmt idempotent on every input fmt accepted (accepted counts below), `--fix` a fixpoint on every input it changed, never wrote on a clean file, never changed CRLF/BOM, never increased the syntax-error count. fmt changed the diagnostic set only for the invisible-char escaping (F10); the "non-whitespace token diff" hits were only `|`, `,`, `'`, `{}` braces for brace-less bodies, `case 1: case 2:` merged to `case 1, 2:` and F10.
- Counters (seed 7, 1,500 cases): `check` exit 0/1 and valid JSON 1,500/1,500; `fmt` accepted 109 (most mutants have syntax errors and are refused), idempotent 109/109; `--fix` changed 509 files, 509/509 fixpoints. Earlier seeds 1-3 (5,150 cases) had the same zero-failure result. Dedicated fmt fuzz (2,500 whitespace-perturbed valid seeds): 1,431 accepted, 649 produced output identical to fmt of the original (the other 782 differ from fmt(original); the 2 inspected were preserved blank lines, the rest not examined; 116 perturbations changed the `?` whitespace rule and were refused as expected), 649/649 idempotent, 649/649 same diagnostic codes.
- Determinism: 427 inputs (127 repo `.oxs` + 300 error-heavy mutants) x 3 runs of `check --json`, byte-compared: 0 differences; directory check of `oxiscript` + `editors` x3: identical md5.
- Line/utf16 positions vs VS Code line rules on 1,500 inputs using `\n \r\n \r U+2028 U+2029 VT FF NEL`, emoji, combining marks: 0 mismatches.
- Nesting 1k..1M levels of `(`, `[`, `-`, `!`, `{`, `if`, lambdas, template `${`, `Array<`, binops, calls, `.b` chains, via check and fmt: always exit 1 with OXS-E0011 in <1.2 s (depth limit 56 held).
- Size scaling check/fmt on 0.28/1.1/4.6 MB: 0.3/1.1/4.2 s, memory ~90 B per source byte (linear). 80k-error file 0.26 s (cap).
- IDL: 200k nested `result<`, 50 MB identifier (4 s, 300 MB), 100 KB random bytes, 200k duplicate `needs`: no crash. Interface count quadratic (F7).
- `--fix` edge files: BOM+CRLF+multibyte, EOF without newline, empty file, tabs, lone CR, unterminated string (guard fires, file unchanged), comments containing `==`, mixed precedence, `a.0.1`, `5.`: correct, meaning preserved (a `&`/`==` mix is parenthesised in the parser's own reading).
- `oxi new`: `../x`, abs path, `.`, `a/b`, uppercase, spaces, empty, `-x`, `x$(id)`, 65 chars, existing dir (sentinel untouched), dangling symlink, bad template: all exit 2, nothing written.
- Extension: `npm test` 20/20; 5 attack tests (3 fail = F3, F11, F12; stale-version drop and shell-metachar paths/oxiPath held up).
- Docs: ~35 claims run through the checker (numbers, `==`, `;`, throw, for-in, `i++`, typeof, any, generics on export, `s.length`, `?.`, extends, Result `?` error mismatch, built-in member list); all true except F4. No prompt-injection-like text, no curl/sudo/chmod, nothing teaching insecure patterns beyond "apply machine-applicable fixes without asking" (safe given the guard, see F5/F6).

## Held up
Depth/size DoS on regular files (not special files, F15), fix convergence guard (never worse than input), no write when clean, JSON validity and UTF-16 columns, `new` hostile names, no shell in the extension (`spawn` without shell; spaces/quotes in oxiPath and file names are plain argv), stale-buffer protection in diagnostics and code actions, `oxi.toml` parse errors are exit 2 not panics, `./` and `../` import specifiers clamp at the root (the package-style branch does not, see F1).

## Recommendations
1. F1: in `FsLoader::load` normalise BOTH branches (reject a leading `/`, any `..` that pops past the root), then canonicalise the final path and assert it starts with the root.
1b. F5/F15: only open regular files (`symlink_metadata`/`file_type().is_file()`, optionally refuse symlinks that leave the root), cap read size, write via temp file + rename.
2. F2: make `check` enforce `needs`: every `host:` import must be listed, every `needs` entry must be a parameter of `main` in order (or drop the claim from templates/docs).
3. F3: set `oxiPath` scope to `machine`, add `capabilities.untrustedWorkspaces: {supported: "limited", restrictedConfigurations: ["oxiscript.oxiPath"]}` and on Windows spawn an absolute path resolved from PATH.
4. F10/F5: make fmt keep BOM and EOL style; F16: stop discovery at `.git` / the first `oxi.toml` / `$HOME`.
5. F6: report "gave up: more than N errors" and compare the uncapped count (or fix per round regardless of cap, validating by re-check).
6. F7: index modules in a HashMap; F8: track canonical dirs visited (or do not follow dir symlinks); F9: report per-file read errors as diagnostics and continue; F17: warn or error on `--stdin --fix`.
7. Docs: F4; add the `needs` truth after F2.
8. Extension: validate `files`/`range` fields in `parseReport`, wrap `check()` in try/catch, limit concurrent spawns (queue of 2-4).
