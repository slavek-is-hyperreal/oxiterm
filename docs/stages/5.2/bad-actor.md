## What held up

- Hostile fuzz (non-finite/huge/negative numbers in every DisplayItem field, random unicode up to U+2FFFF, bad cluster indices, stray Push/PopClip, scale 0.25..3, mixed sink reuse): 1500 seeds x 300 items = 450k items, 0 panics, 0 errors, worst frame 110 ms, RSS +49 MB.
- Readback row padding exact (coded colour per pixel) at 1x1, 1x3, 3x5, 63, 64, 65, 257, 4096, 4097 wide.
- Scissor edges: x==width/w==0, fully outside, +-1e30, negative sizes, NaN/inf clips, 100k nested clips + 200k pops: ok, 9 ms.
- `GpuSink::new` with scale 0, -1, NaN, +-inf, 1e6, 1e-9: clamped, no panic.
- Atlas key: no collision between sizes 12.0/12.3 or bold/normal (key uses exact f32 bits); atlas thrash (46 resets, 6 frames x 1500 sizes/styles) then CPU equality (worst tile 5 px).
- A sink cannot outlive its context (it holds `Arc<GpuContext>`), so use-after-context-drop is impossible by construction.
- Determinism: sink A, then B after thrash, then A after atlas clear: byte equal. 4 threads x 40 frames, own sink each on one `Arc<GpuContext>` (context is Send+Sync): all byte equal to the single-thread render; the readback wait is race free there.
- Long mono run 100k vs 400k glyphs: 33 ms vs 103 ms (linear). 1000 identical frames: RSS +0 KB. 600 size flips: +9.6 MB (noise-level). 64 sinks on one context: 2.1 MB per sink, 0.6 s.
- Weird text (combining, ZWJ, RTL, controls, U+FFFF, sizes 0.1..1e9, NaN, 10k-mark and 62-mark clusters x 2000): ok, 264 ms. Fractional x += 0.1 x 10k items: 0 px diff vs CPU.
- Italic, underline, sans bold, wide CellGrid, nested clips: exact vs CPU in per-feature scenes.

## Recommendations

1. Wrap each frame in `push_error_scope(Validation|OutOfMemory)` pushed/popped on the same thread; map to `GpuError` (fixes B-01/02/03/06 together). Validate view format/size/usage in `render_into_view` (also cheap and gives a precise error).
2. Cap instance buffers (F-01) and shrink them (or cap Vec capacity) after a frame that used < 1/4 of capacity (B-05).
3. Bound `entries`: do not cache `None` entries for blank glyphs, or cap `entries.len()` and reset, like the CPU 64 MiB budget (B-04).
4. Per-feature differential scenes with <= 12 px per 16x16 tile (B-07); fix bold batching (F-12). Investigate the rounded-edge bias against an analytic reference before touching tolerances (B-08).
5. In the tests, skip only on `NoAdapter` (F-05).
