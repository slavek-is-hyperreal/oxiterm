## Caveats (read before acting)

* F-02 "pre-existing": taken from the implementation notes (the pre-7.6 loop checked `is_within_base`); not verified, no git here.
* F-01 is demonstrated at the frame-sink level (bytes not re-sent for the same `src` after `current_page` changes with the epoch unchanged); "the browser keeps the old image" is inferred from `mediaCache` being keyed by the same hash, not observed.
* Not covered: hostile Lottie JSON in the browser lottie-web player (tab hang), a media-pool / src-swap race in a real browser, a real SSH terminal, the "only 8 goldens changed" claim (no git).
* Deviations from the allowed test paths: `oxiterm-proto/tests/bad_actor_76.rs` (not `src/pathsafe/`, to avoid a `mod` line in product code), `scripts/bad_actor_76_ws.py` and `scripts/bad_actor_76_deeplink.mjs` (one Python probe, one mjs).

## What held up

* Resolver: `../`, absolute, `//`, `\`, NUL, schemes, `%2e/%2f/%5c` any case (refused); double-encoded `%252e`, fullwidth dots U+FF0E, U+2025, overlong `%c0%ae`, `?`/`#` are literal names inside the base (safe: nothing decodes a `src` on the server); symlink file, dir, chain, relative link, missing file below a symlinked dir, `/etc`: refused; base itself a symlink: OK; 200 000-segment `../` or `a/`: fast in the lexical layers.
* Local mode `.json`/`.mmd`: the index is built only from `.thtml` files on disk (not hidden dirs, no symlinks, no multi-linked); a page naming `../x.json`, `../../x.json`, `%2e%2e/x.json`, `..\x.json` produces no entry (`media_rel_path` returns None); 27 request forms for an unnamed file, case variants, `%00`, `%2f`, `.`/`..`, `//`, dotfiles all 404; not named = not served (`config.json`, `package.json`, other `.mmd`); a page in a hidden directory does not count. A visitor cannot add entries. Observed live: `GET /oxiui/local/asset/assets/bell.json` 200, `../../etc/passwd` 404.
* Mermaid: server parser caps 64 KiB / 256 nodes / 512 edges; worst in-cap case (256 nodes, 512 edges) 52 ms, 60 KB label 5 ms; beyond-cap inputs rejected in < 6 ms. Browser mount cap 256 KiB.
* Viewport clamped at 500x200 (`clamp_dims`), so no unclamped raster sizes; rive rasteriser has no panic path (zero/odd sizes return empty).
* Client: `#media-layer` is `pointer-events:none; overflow:hidden`, sized to the canvas, so overlays cannot clickjack outside the canvas; SVG goes through `<img>` (no script); vendored lottie-web light has no `eval`/`new Function`; version string `5.12.2` (check it against a current advisory list; not cited here, no network). No provenance/checksum file for the vendored script is in the repo.
* Static sites copy: `sites/build.mjs` does not copy `oxiui/vendor/`, so Lottie is empty there (slot `data-lottie=failed`); with the strict `script-src 'self'; style-src 'self'` CSP this is harmless (element `style.cssText` is CSSOM and allowed). Not verified in a browser.
* Regression: `oxiterm-proto` 16+5, `oxiterm-renderer` 162 + media_parity 8 + goldens 1 + rlottie 4 etc., `oxiterm-core` 91+4+3, `oxiterm-server` 159 + 9 + 3 + 4 + 2 + 3(+7 ignored), `oxiterm-web --features local` 31+7+7+3: all pass (release). `cargo build --release -p oxiterm-core --target wasm32-unknown-unknown` OK; `cargo tree` for core/web on wasm32 has no rlottie/resvg/ffmpeg/tiny-skia/cc. Golden snapshots pass against the committed baselines; "only the 8 blessed changed" is **not independently verified** (no git).

## Recommendations (in order)

1. Bound the Rive web cost (cache the half-block image per size and state like the Kitty/Sixel path; cap the raster size) (F-13). Percent-decode `page=` once server-side before the traversal check (F-11, low).
2. Key `sent_assets`, `sent_coordinates` and the client cache by the resolved path (or hash of it), not the raw `src`; use a 64-bit hash or the full string (F-01, F-09).
3. In `sync_preamble` reuse the 7.1 asset-route discipline: open once, `fstat` the descriptor (`is_file`, size cap, nlink), read from the descriptor; refuse dotfiles and non-media extensions (F-02, F-03, F-04, F-07, F-08). Same post-open path check for the local route (F-10, `O_NOFOLLOW` or `openat2 RESOLVE_BENEATH`).
4. Make `PlaybackRegistry` session-scoped (key by session id) (F-12); bound its map.
5. Parse Lottie in a size-capped, time-bounded, ideally separate process, outside the registry mutex; cap file size (F-06). Add an advisory check for rlottie and lottie-web 5.12.2 to the release checklist.
6. Cap `src` length and make `canonical_prefix` single-pass (F-05). Optional: cap Rive raster size (F-13).
7. Add `X-Content-Type-Options`, `frame-ancestors` and a CSP to `/` (F-14).
